# Tài Liệu Triển Khai & Kiểm Chứng An Ninh Hệ Thống (Security Hardening) — Đề 32

Tài liệu này ghi lại chi tiết các biện pháp phòng thủ theo chiều sâu (Defense-in-Depth) đã được áp dụng trong hệ thống Chat Đề 32, kèm theo phương pháp kiểm chứng thực tế và đánh giá hạn chế tồn tại.

---

## Bảng Tổng Hợp Các Biện Pháp Bảo Mật

| STT | Biện pháp bảo vệ | File cấu hình liên quan | Mục đích an ninh | Cách thức kiểm chứng | Kết quả thực tế | Hạn chế còn tồn tại |
|---|---|---|---|---|---|---|
| **1** | Chạy ứng dụng bằng Non-root user (`node`) | `backend/Dockerfile`, `docker-compose.yml` | Giảm thiểu nguy cơ leo thang đặc quyền (Privilege Escalation) nếu ứng dụng bị chiếm quyền | `docker compose exec chat-app id` | Trả về `uid=1000(node) gid=1000(node)` (Non-root) | Môi trường dev cục bộ có thể cần mount file với đúng quyền của user node |
| **2** | Phân tách mạng nội bộ (Network Segmentation) | `docker-compose.yml` | Cô lập tầng Database, ngăn chặn việc tấn công trực tiếp từ bên ngoài hoặc từ tầng Proxy | Kiểm tra `docker network inspect` và thử kết nối trực tiếp cổng 5432 từ máy host | Cổng 5432 không public ra host; Nginx không thấy được container Postgres | Cần cấu hình đúng network alias khi mở rộng thêm service |
| **3** | Không lộ lọt Secrets, Keys vào Git | `.gitignore`, `.env.example` | Ngăn chặn việc lộ lọt mật khẩu, JWT secret và chứng chỉ SSL lên GitHub | Kiểm tra `git status --ignored` và xem lịch sử commit | File `.env`, `chat.key`, `chat.crt` hoàn toàn bị git bỏ qua | Người dùng phải tự tạo `.env` từ `.env.example` trước khi chạy |
| **4** | Dùng tài khoản DB chuyên biệt (`chat_user`) | `docker-compose.yml`, `backend/src/config/index.js` | Tuân thủ nguyên tắc đặc quyền tối thiểu; không sử dụng superuser `postgres` cho ứng dụng | `SELECT current_user;` từ backend connection | Đăng nhập với quyền `chat_user`, chỉ thao tác trên database `chat_db` | Tài khoản vẫn có toàn quyền DDL trên schema nếu cần chạy migration tự động |
| **5** | Băm mật khẩu bằng Bcrypt với Salt | `backend/src/modules/auth/auth.service.js` | Chống tấn công Rainbow table và bảo vệ mật khẩu người dùng nếu DB bị rò rỉ | Kiểm tra trường `password_hash` trong bảng `users` | Mật khẩu được lưu dưới dạng chuỗi băm chuẩn `$2a$10$...` | Bcrypt tốn CPU khi scale hàng nghìn request login đồng thời (có thể chỉnh salt round) |
| **6** | Xác thực & Giới hạn kích thước đầu vào | `backend/src/middleware/validate.js`, `backend/src/app.js` | Chống tấn công XSS, SQL Injection và Buffer Overflow/DoS qua payload lớn | Gửi request có username sai định dạng hoặc tin nhắn > 2000 ký tự | Server từ chối ngay lập tức với mã lỗi HTTP 400 Bad Request | Chưa hỗ trợ kiểm tra mã độc trong file đính kèm (do đề tài là text chat) |
| **7** | Xác thực JWT & Kiểm tra quyền phòng chat | `backend/src/middleware/auth.js`, `backend/src/socket/index.js` | Bảo vệ toàn bộ REST API và WebSocket; ngăn chặn việc nghe lén phòng riêng tư | Gọi API không kèm token hoặc cố join vào phòng private khi chưa là thành viên | Bị chặn với mã lỗi HTTP 401/403 hoặc từ chối handshake WebSocket | Chưa tích hợp cơ chế Refresh Token xoay vòng (Token Rotation) |
| **8** | Giới hạn tần suất yêu cầu (Rate Limiting) | `backend/src/middleware/rateLimiter.js` | Chống tấn công Brute-force mật khẩu và tấn công từ chối dịch vụ (DoS) | Chạy vòng lặp gọi POST `/api/auth/login` > 20 lần trong 15 phút | Server phản hồi HTTP 429 Too Many Requests | Rate limit hiện lưu trên bộ nhớ ứng dụng (in-memory), chưa dùng Redis phân tán |
| **9** | Thiết lập Security Headers & Ẩn phiên bản Nginx | `nginx/nginx.conf`, `nginx/conf.d/chat.conf`, `backend/src/app.js` | Ngăn chặn tấn công Clickjacking, MIME-sniffing, XSS và dò quét lỗ hổng phiên bản | Kiểm tra response headers bằng `curl -I https://localhost:8443` | Có đủ `X-Frame-Options`, `X-Content-Type-Options`, không có `Server: nginx/x.x` | CSP đang mở một số directive cho CDN Socket.io để phục vụ demo nhanh |
| **10** | Chặn leo thang đặc quyền container (`no-new-privileges`) | `docker-compose.yml` | Ngăn chặn tiến trình con nhận thêm quyền hạn thông qua bit setuid/setgid | Kiểm tra trong `docker inspect chat-app` mục `SecurityOpt` | Có `no-new-privileges:true` | Không áp dụng được read-only filesystem cho container cần ghi tmp cache |
| **11** | Không mount Docker Socket vào Ứng dụng Chat | `docker-compose.yml` | Tránh lỗ hổng container breakout chiếm quyền điều khiển Docker daemon máy chủ | Kiểm tra volume mount của service `chat-app` | Không có `/var/run/docker.sock` trong container `chat-app` | Promtail và cAdvisor vẫn cần mount read-only socket để thu thập log/metrics |
| **12** | Khử thông tin nhạy cảm trong Log (Sanitization) | `backend/src/logger/index.js` | Ngăn chặn việc ghi mật khẩu, JWT token, cookie vào stdout/Loki | Đăng nhập và xem log tạo ra trong console hoặc Grafana | Các trường `password`, `token`, `authorization` được thay thế bằng `[REDACTED]` | Log dạng plain text không qua parser vẫn có thể vô tình lọt nếu dev ghi đè |
